# 843 真题墙工程状态

更新时间：2026-10-29。

## 当前结构

- Next.js 16 App Router 静态导出，部署到 GitHub Pages `/your-study-wiki/`。
- `ProtectedGate` 用配对密钥解密题库和公式卡；页面源代码与密文公开，明文资料不进入 Git。
- `StudyWallDashboard` 提供分类、套卷、做题、收藏、错题复测、真题掌握与公式知识点界面。
- 掌握标记、收藏、笔记、草稿、学习足迹先保存在浏览器，连接 GitHub 后自动同步至独立的 `study-sync` 分支。
- Windows 本地入口运行静态服务器，使用与 Pages 相同的构建，不依赖常驻 Next 开发服务。

## 本轮完整性检查

- 修正加密准备脚本：保留既有盐值，先验证密钥和现有资源，只重加密内容变化的文件。避免更新题库时使设备授权及云端学习记录失效。
- 修正本地自动解锁：优先清除启动 URL 中的配对片段；IndexedDB 不可用时仍能尝试本地配对。
- 修正同步限额判断：HTTP 200 即为成功；仅对 429 或明确的 403 限额响应退避。
- 全仓库 lint 排除临时浏览器测试资料，避免无关扩展代码造成大量误报。
- 题图解密或下载失败时显示失败状态与重试入口，避免无限加载。
- 增加独立加密准备测试，覆盖重复执行、错误密钥拒绝和仅更新变化资源。
- 构建前自动注入最新密文；本地服务和 Pages 同步会检查题库与公式密文是否齐全。

## 验证与限制

- `npm run typecheck`、`npm run lint`、`npm run test:integrity` 和带 `/your-study-wiki` base path 的静态构建是发布门槛。
- 题库与年度卷的数学准确度依赖上游分类册校订；工程检查不等于逐题内容审核。2025 年已知缺损仍在。
- 当前没有服务端身份认证或数据库。Pages 的访问保护依赖加密密钥，学习记录同步依赖用户自己的 GitHub PAT。
- 当前不支持断网后从零重新打开题库；已经打开的页面可继续使用本地记录。
- `docs/TODO.md` 等早期原型文档仍为历史记录，不代表当前功能状态。
